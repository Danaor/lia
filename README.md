# Lia

**L.I.A - Local Inference Assistant** for Windows 10 / 11.

## Download

Get the latest version from the [releases page](https://github.com/Danaor/lia/releases/latest):

- **`Lia-Setup`** - the installer (no admin rights needed).
- **`Lia-Portable`** - no installation: extract the zip anywhere and double-click `Lia.bat`.

After the first start Lia sits in the tray, next to the clock. Click the icon to open it.

Windows SmartScreen may warn on the first run because Lia is not code-signed yet: click *More info* > *Run anyway*. Lia checks for new versions and updates itself when you click *Update*.

## Troubleshooting

- **Locked / corporate PC, `Lia.exe` blocked ("Access denied"):** run **`Lia (Work PC).bat`** from the portable folder.
- **The window does not open after extracting the zip:** right-click the zip > Properties > **Unblock**, then extract it again.
- **Lia is not in the tray after a reboot:** Settings > Advanced > *Report a problem* collects what is needed to find out why (personal details removed).
- **The tray icon is hidden** behind the `^` arrow: drag it next to the clock once and it stays.
